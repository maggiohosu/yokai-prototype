# 요괴 성장 게임(yokai-game) 여의주 강화 및 상점 효과음 (SFX)

동양 설화풍 귀여운 요괴 성장 게임(모바일 웹)의 **여의주(구슬 무기) 강화 연출** 및 **상점 엽전 판매** 연출용 효과음 6종입니다.  
검 강화 게임 스타일의 높은 텐션과 짜릿한 보상감을 제공하도록 디자인되었습니다.

외부 녹음본이나 저작권 라이브러리를 사용하지 않고, Python DSP 신시사이시스 알고리즘을 통해 100% 코드로 자작 합성되었습니다.

---

## 1. 파일 목록 및 규격

## 2. 제작 방법 및 생성 스크립트

- **생성 스크립트 경로**: [`assets/sfx/generate_sfx.py`](generate_sfx.py)
- **합성 기법**:
  - **가산 합성 (Additive Synthesis)**: 편종 및 풍경의 물리적 고유 배음비(`[1.0, 2.76, 5.4, 8.9]`) 재현
  - **주파수 변조 (FM Synthesis)**: 징의 금속성 잔향체 및 긴장감 상승 모듈레이션
  - **물리 모델링 & 과도응답 제어**: 엽전 및 파편 산란 물리적 튕김 딜레이와 감쇠 상수 모델링
  - **다이내믹스 & 마스터링**: `-1.2 dBFS` 피크 노멀라이제이션 및 코사인 윈도우 페이드 인/아웃 적용
- **포맷 인코딩**:
  - `WAV`: 44.1kHz 16-bit PCM Linear
  - `OGG`: Vorbis 코덱 (qscale 4, ~128kbps 모노)
  - `MP3`: LAME 코덱 (128kbps 모노)

### 재현 및 빌드 명령어
```bash
python assets/sfx/generate_sfx.py
```
*(요구 환경: Python 3.x, numpy, scipy, ffmpeg)*
