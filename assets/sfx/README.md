# 요괴 성장 게임(yokai-game) 사운드 효과음 (SFX) 라이브러리

동양 설화풍 귀여운 요괴 성장 게임(모바일 웹)의 **여의주 강화 및 상점 판매 연출**, **보패 무기 7종 발사 연출**, **상점 및 시스템 연출**, 그리고 **필드 인게임 조작 및 전투 효과음** 총 22종입니다.  
검 강화 게임 스타일의 높은 텐션과 짜릿한 보상감, 그리고 귀여운 동양풍 판타지 액션의 찰진 타격감을 제공하도록 디자인되었습니다.

외부 녹음본이나 상용 저작권 라이브러리를 일절 사용하지 않고, Python DSP 신시사이시스 알고리즘을 통해 100% 코드로 자작 합성되었습니다.

---

## 1. 파일 목록 및 규격

모든 음원은 **44.1kHz 모노(Mono)**, **무클릭 코사인 페이드(Fade in/out)** 가 적용되어 있으며, 모바일 웹 환경에 최적화되도록 **WAV**, **OGG**, **MP3** 3가지 포맷으로 제공됩니다. 모든 OGG/MP3 파일은 60KB 이하 기준을 완벽히 충족합니다.

- **발사음 규격**: 재생 시간 ≤ 0.18초, 음량 기준 기존 대비 -6dB 이하 (-7.50 dBFS 정규화), 피크 ≤ -1 dBFS
- **시스템/상점 규격**: 재생 시간 ≤ 1.20초, 피크 ≤ -1 dBFS (-1.50 dBFS 정규화)
- **필드 효과음 규격**: 자주 재생되는 음원은 귀 피로를 줄이기 위해 고음 날카로움을 억제하고 음량 감쇄(-6dB/-8dB) 적용, 부스터 루프는 끊김 없는 심리스 루프(Seamless Loop) 적용

## 2. 제작 방법 및 합성 기법

- **생성 스크립트 경로**: [`assets/sfx/generate_sfx.py`](generate_sfx.py)
- **합성 기법 개요**:
  - **가산 합성 (Additive Synthesis)**:
    - 편종, 풍경, 청동 방울의 고유 배음비(`[1.0, 2.76, 5.4, 8.9]`) 재현
    - 팔괘경(Bb6, 1864Hz) 및 삼청령(C#7 2217Hz, F7 2793Hz) 비정수 금속성 모드 합성
    - 궁중 제례악 및 동양 5음계(궁·상·각·치·우) 선율 아르페지오 (해금 팡파르, 상점 완료 차임)
  - **주파수 변조 및 피치 스윕 (FM & Chirp Synthesis)**:
    - 징의 금속성 잔향체 모듈레이션
    - 단호로 약수 물방울 솟구침 지수 피치 스윕 (480Hz -> 1320Hz)
    - 여의주 발사 곡선형 피치 스윕 (650Hz -> 1450Hz -> 500Hz)
    - 옥인 저역 펀치 및 피격 하강 슬라이드
  - **대역통과 필터 및 난수 노이즈 모델링 (Filtered Noise Shaping)**:
    - 학우선 깃털 풍절음(800Hz~2600Hz) 및 도목검 목재 검풍
    - 부스터 켜짐 제트 풍절음 및 공기 마찰 과도응답
  - **심리스 루프 합성 (Seamless Cyclic Loop Synthesis)**:
    - `boost-loop`: 주기 $T=0.60$초에 완전히 일치하는 주파수 군집($f_k = k/T$) 가산 합성과 정수 주기 진폭 일렁임(5Hz)을 적용하여, 시작점과 끝점의 진폭 및 1차 미분이 완전히 연속되어 루프 시 클릭 노이즈가 전혀 발생하지 않도록 설계
  - **귀 피로 방지 다이내믹스 (Fatigue-Free Dynamics)**:
    - `eat`, `orb-hit`, `orb-fire` 등 전투 중 초당 수 회 이상 빈번하게 발생하는 효과음은 3.5kHz 이상의 날카로운 고주파를 억제하고 음량을 기준 대비 -6dB ~ -8dB 낮게 세팅(-7.5 dBFS ~ -9.5 dBFS)하여 청각 피로를 방지
  - **다이내믹스 & 마스터링**:
    - 모든 효과음 시작/끝 지점에 무클릭 코사인 윈도우 페이드 인/아웃 적용
    - 피크 노멀라이제이션 (발사음 -7.50 dBFS, 시스템 -1.50 dBFS, 필드 -2.0 ~ -9.5 dBFS)

- **포맷 인코딩**:
  - `WAV`: 44.1kHz 16-bit PCM Linear Mono
  - `OGG`: Vorbis 코덱 (qscale 4, ~128kbps 모노)
  - `MP3`: LAME 코덱 (128kbps 모노)

### 재현 및 빌드 명령어
```bash
# 신규 음원 생성 (기존 6종 파일은 보존)
python assets/sfx/generate_sfx.py

# 전체 음원 강제 재생성 필요 시
python assets/sfx/generate_sfx.py --all
```
*(요구 환경: Python 3.x, numpy, scipy, ffmpeg)*
