# 난이도 검증

헤드리스 Chrome 158.0.8127.36에서 일반 시작 주소 `http://127.0.0.1:8765`를 열었다. 새 브라우저 컨텍스트를 사용해 실제 사용자 저장소와 분리했다. 전체 Node 테스트 677개가 통과했고, `src`와 `tests`의 JavaScript 파일 110개가 `node --check`를 통과했다.

## 하드 슬롯의 목숨

| 동작 | 결과 |
|---|---|
| 2번 칸에서 새로 시작하고 하드 선택 | HUD와 저장소에 목숨 10. [난이도 카드](01-difficulty.png) · [하드 HUD](02-hard-hud-10.png) |
| 판 중 정비에 들어갔다 돌아오기 | 목숨 10 |
| 큰 적에게 먹힌 첫 판 | 결과창과 저장소에 9. 다시 시작 화면을 열면 2번 칸에 하드와 목숨 9 표시. [결과창](03-defeat-9.png) · [슬롯 카드](04-saved-slot-9.png) |
| 이어하기 후 특수 요괴의 구슬로 쓰러짐 | 결과창과 저장소에 8 |
| 다음 판을 시작해 연속 패배 | 판마다 결과창과 저장소가 7 → 6 → 5 → 4 → 3 → 2 → 1로 일치 |
| 마지막 패배 | 결과창에 ‘남은 목숨 0 · 캐릭터가 사라졌습니다.’ 표시. 결과창이 열린 시점에 2번 칸의 저장 키가 이미 없어졌다. [마지막 결과](05-final-defeat.png) |
| 시작 화면으로 복귀한 뒤 새로고침 | 2번 칸은 비었고 이어하기 버튼은 0개. 1번 칸의 이지 저장 데이터는 첫 판 전과 동일했다. [복귀 직후](06-title-after-erasure.png) |
| 새 하드 캐릭터가 5단계·크기 150에서 승천 | 승천 결과창과 저장소 모두 목숨 10. [승천 결과](07-ascension-10.png) |

검증에서는 큰 적을 플레이어 위치에 놓아 게임의 충돌 처리를 실행했다. 두 번째 패배는 적 구슬 피해 처리로 유도했다. 승천 검증에서는 단계와 크기를 목표값에 맞춘 뒤 다음 시뮬레이션 프레임에서 게임이 판을 끝내게 했다. 목숨과 결과창은 모든 경우 게임 코드가 갱신했다.

목숨 소모 기준은 먹힘과 쓰러짐이다. 슬롯 선택, 정비, 새로고침, 승천으로는 차감하지 않는다. 마지막 판의 종료 이벤트도 일반 자동 저장과 같은 경로를 사용하며, 그 경로에서 목숨이 0인 슬롯을 지운다.

## 이지 조작

강화 0의 플레이어 이동 속도는 노말 65.5, 이지 131 월드 단위/시뮬레이션 초였다. 같은 크기와 단계에서 적의 이동 속도는 두 난이도가 같다. Shift를 누른 동안 이지 부스터 배율은 1, 게이지 잔량은 2초였고 부스터 입력은 꺼져 있었다. 화면에 보이는 부스터·발사 버튼 수는 각각 0개였다. [이지 HUD와 자동 발사](08-easy-auto-fire.png)

이지의 기본 여의주는 발사 입력 없이 시뮬레이션 시각 0.5622초, 1.1131초, 1.6643초에 연속 발사했다. 설정 쿨타임은 0.55초다. 정비창을 1.25초간 열어 두었을 때 추가 발사는 0회였고, 닫자 자동 발사가 재개됐다.

## 적 단계별 출현 확률

각 칸은 적 **1단계 / 2단계 / 3단계 / 4단계 / 5단계**의 확률(%)이다. 이지는 나보다 낮은 단계, 하드는 높은 단계의 기존 가중치에 1.4를 곱한 뒤 전체 합으로 나눴다. 소수 둘째 자리까지 표시해 합계에 0.01%p 차이가 날 수 있다.

## 같은 단계의 적 크기

각 칸은 **작음 / 비슷함 / 큼**의 확률(%)이다. 플레이어가 자라는 도중에는 기존 크기 분포를 먼저 보간한다. 그다음 같은 단계의 적에게만 이지의 작은 구간 또는 하드의 큰 구간 가중치를 조정한다. 노말은 기존 가중치와 크기·단계의 난수 추첨 순서를 사용한다.

| 플레이어 크기와 단계 | 노말 | 이지 | 하드 |
|---|---|---|---|
| 판 시작 크기, 모든 단계 | 35 / 15 / 50 | 42.98 / 13.16 / 43.86 | 29.17 / 12.50 / 58.33 |
| 초반 크기 구간을 지난 1·2단계 | 67 / 13 / 20 | 73.97 / 10.25 / 15.77 | 62.04 / 12.04 / 25.93 |
| 초반 크기 구간을 지난 3~5단계 | 45 / 15 / 40 | 53.39 / 12.71 / 33.90 | 38.79 / 12.93 / 48.28 |

## 검증 재실행

저장소 루트에서 `node --test "tests/*.test.mjs"`를 실행한다. 브라우저 검증은 게임을 8765 포트로 제공하는 상태에서 Python Playwright와 설치된 Chrome을 사용한다. 아래 명령은 지정한 폴더에 새 캡처를 기록한다.

```powershell
python docs/design-review/difficulty/verify.py docs/design-review/difficulty
```
