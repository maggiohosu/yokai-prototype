# 강화 성공 부가 옵션 후보 30종

- 작성: 2026-11-23. 코드(src/, tests/)는 건드리지 않음. 확정 수치가 아니라 밸런스 조정용 초안이다.
- 출처 안내: 이 문서는 외부 검색 결과가 아니라 docs/spec.md(7·8절)의 규칙과 기존 능력치 3종에 맞춰 설계한 제안이다. 웹 조사는 하지 않았다.
- 원칙(spec 기획 원칙 유지): 형태마다 고유 기능 없음, 수치로만 차이. 아래 옵션은 모두 "어떤 수치를 몇 % 바꾸는가"로만 정의하며 새 규칙·새 조작·형태 전용 효과를 만들지 않는다.
- 부여 규칙 제안: 본체 강화에 성공할 때 일정 확률로 옵션 1개가 붙는다(최대 슬롯 3, 같은 옵션 중복 불가). 수치는 현재 등급 배율(S+ ×2.0 ~ F ×0.5)을 따른다. 확률·수치는 게임 안에 표시한다. 요력으로 살 수 없고 과금과도 무관하다.
- 수치 열은 기본값(등급 ×1.0 기준)이고 범위는 +1~+10 강화 구간에 따라 늘어나는 폭이다.

## 7. 밸런스 제안

- 옵션 합산에 상한을 둔다. 같은 계열(이동·공격 등) 합산이 +30%를 넘지 못하게 하고, 능력치 3종 강화와 곱하지 않고 더한다.
- 확률 층 수는 spec 6항(최대 7개)을 지키기 위해 "옵션 부여"를 새 확률 층으로 세지 않고, 본체 강화 성공 판정의 부속 굴림으로 처리한다. 이 해석은 조정자 확인이 필요하다.
- 퇴화 선택 B(역진화)가 일어나면 옵션은 유지하되 형태가 바뀌어도 수치 옵션이라 그대로 적용된다. 퇴화 선택 A면 가장 최근 옵션 1개를 잃는 안을 검토할 수 있다.
- 옵션 이름은 한글 2~5자로 짧게 한다. 형태별로 어떤 옵션이 잘 붙는다는 편향은 두지 않는다(고유 기능 금지 원칙).
- 구현 시 필요한 것: 옵션 표(id, 이름, 영향 수치 키, 기본 수치 범위), 부여 확률, 슬롯 수. 아직 코드에 해당 필드는 없다.
