# 요괴 키우기 시제품 — 설계 (Opus 작성, 2026-11-22)

## 역할
- 계획·점검·검수·조사: Claude Opus 5.5
- 코딩: Codex(GPT)와 Antigravity가 단계별로 번갈아 맡음 / Sonnet 5.5: 작은 수정, 데이터(진화표·설명문)
- 단계별로 GitHub Pages에 게시함

## 기술
- 정적 사이트(빌드 없음). index.html + ES 모듈(src/*.js). Phaser 3.90을 jsDelivr CDN에서 불러옴.
- 세로 화면 고정, Phaser.Scale.RESIZE, 터치 입력, devicePixelRatio 대응.
- 캐릭터: Phaser Graphics로 부품을 그린 뒤 generateTexture로 구워 씀(형태+등급별 캐시).

## 파일 구조
- index.html — 캔버스, 메타 viewport, 모듈 진입
- src/config.js — **모든 수치**(확률·비용·속도·크기·줌·쿨타임·AI 거리·구역 색 비율)
- src/data/forms.js — 형태 17종: id, 이름, 단계, 방위(east/west/south/north/none), 갈래(yo/seon/none), 부품 목록, 한 줄 설명, 진화 경로
- src/art/creature.js — drawCreature(scene, formId, opts) → texture key. 부품 함수 모음
- src/game/ — world.js(맵·구역·스폰), player.js, enemy.js(AI 3규칙), joystick.js, camera.js
- src/scenes/ — PlayScene, (3단계) EvolveScene, (4단계) HubScene
- src/state/ — (3단계) progress.js, (5단계) save.js(localStorage)

## 수치 초안(설정값에 둠, 기획서에 없던 것)
- 진화 비용: 2단계 100 요력, 3단계 400 요력
- 요력 획득: 먹은 요괴 크기 × 1(반올림), 보물로 쓰러뜨리면 ×1.5
- 등급 보정: 본체 강화 레벨 합계 1당 F·E·D 확률에서 0.5%p를 빼서 S+:S:A:B = 1:2:3:4 비율로 더함(최대 합계 30)
- 퇴화 비율 구간: +1~4 0%, +5~6 30%, +7~8 40%, +9~10 50%
- 판 안 레벨업 카드 주기는 다음 버전(15~20초)

## 단계
1. 이동·먹기·크기 판정·적 AI·카메라 줌아웃
2. 발사 버튼·여의주·자동 조준·깎기·역전 표시
3. 요력·식성·성향·1~3단계 진화(3택·등급)
4. 판 사이 화면: 본체 강화(퇴화 A/B), 여의주 강화·판매
5. 저장(localStorage)


## 변경 이력 (사용자 지시, 2026-11-22 밤)
- 초반(플레이어가 작을 때) 나보다 큰 적이 훨씬 많이 나오게. 커질수록 기존 분포로 돌아감.
- 발사체: 처음엔 이동 방향으로만 발사(자동 조준 없음). 보물(여의주·보패) 강화 레벨에 따라 발사 수·방향 수·속도·파워 증가, +8부터 약한 유도.
- 먹히면 즉시 판 종료 → 결과 창에 [다음 판 시작](주) / [강화·진화](보조).
- 조작: 화면 어디를 눌러도 캐릭터 기준 그 방향으로 이동(조이스틱 대체), 반응 10ms(지연·완충 제거) → 20ms로 조정(사용자 지시, 2026-11-23), 발사 버튼은 계속 사용.

## 변경 이력 2 (사용자 결정, 2026-11-22 밤)
- 적도 플레이어와 같은 구조: 먹어서 커지고(면적), 요력이 쌓이면 스스로 진화(크기 초기화, 식성 1위 방위로 형태 결정, 등급 굴림)·몸집 강화.
- 판 안 진화·강화: 요력(화폐 하나 유지)이 다음 선택지 비용에 닿으면 게임이 잠깐 멈추고 3장 중 선택 — [진화](3단계 미만, 크기는 초기로) / [몸집 강화](확정, 크기 ×1.2, 판마다 초기화) / [능력 강화](성장·속도·효과 중 하나, 기존 성공률·대성공·퇴화 A/B 규칙) / [계속하기].
- 진화한 모습은 판이 끝나도 유지(다음 판은 그 모습, 크기만 초기).
- 먹기 규칙: 같은 단계 = 1.1배 이상 큰 쪽. 다른 단계 = 상위가 먹음, 단 하위가 상위의 2배 이상 크면 하위가 먹음. 보물로 깎아 쓰러뜨리기는 단계 무관.
- 점수(요력) = 크기^1.6 × 단계 배율(1·4·16) × 등급 배율 × 보물 처치 1.5 × 특수 적 8. 크고 높은 단계 하나 > 작고 낮은 단계 여러 개.
- 1단계 적: 방위 색 미물(디자인: Codex).

## 변경 이력 3 (사용자 결정, 2026-11-23)
- 진화 단계 3 → 5단계(4·5단계는 용·신선 쪽). 형태 약 170종(1단계 8 / 2단계 24 / 3단계 60 / 4단계 50 / 5단계 28). 산해경 원문·도감 조사(docs/research-bestiary.md) 기반.
- 강화: 능력치 3종 유지 + 강화 성공 시 붙는 부가 옵션 약 30종(수치 효과만, 고유 기능 금지).
- 그림: 검색 이미지는 참고만, 부품 조립식으로 새로 그림. ComfyUI + IPAdapter로 같은 그림체의 참고 시안을 뽑아 디자인 참고로 쓴다(게임에 직접 넣지 않음).
- 판 안 성장: 요력이 기준에 닿으면 화면 가운데 카드 3장(카드 하나 = 결과 하나: 특정 형태 진화 / 몸집 ×1.2 / 능력 +1). 탭하면 바로 적용하고 게임이 이어진다. 판 안 능력 강화는 실패·퇴화 없이 확정 +1(비용은 더 높게). 확률 강화는 판 사이 허브에서만.
- 화면: 가로(landscape) 진행. 좌하단 고정 이동 스틱(손가락이 캐릭터를 가리지 않게), 우하단 발사 버튼. 터치 방향 반응 20ms.
- UI의 'AI 티' 제거: unslop·hallmark 기준 감사와 정리(docs/design-audit.md).
- 속도 곡선: 게임 전체 템포와 플레이어 이동 속도 둘 다 처음엔 지금의 0.5배, 진화 단계(절반)와 이동 속도 강화 레벨(절반)이 오를수록 빨라져 최종 1.5배(5단계·속도 +10). 기존 이동 속도 강화 효과는 이 곡선에 흡수.
- 여의주 위력은 여의주(보물) 강화 레벨로만 오른다. 능력치 '대표 효과'는 없애고 '생명력'으로 대체(저장된 레벨은 그대로 옮김).
- 생명력: 나를 먹을 수 있는 적과 닿아 있는 동안 게이지가 줄고 그동안은 먹히지 않는다. 최대 0.6초 + 레벨당 0.25초. 위협과 떨어지면 자동 회복(빈 상태→가득 4초). 특수 적 구슬도 생명력이 먼저 막고, 모자라면 크기가 준다.
- 속도 곡선 시작값을 0.5배 → 1/3배로 낮춤(최종 1.5배 그대로).
- 여의주 발사체: 진화 줄기마다 하나(모양·색·궤적 + 속도·크기·퍼짐의 작은 수치 차이), 단계가 오를수록 화려하게. 고유 기능은 두지 않는다.
- 보물로 깎여 작아진 적도 요력은 깎이기 전 가장 컸던 크기로 준다.
- [원칙 변경] 여의주 능력은 진화 줄기마다 고유하다(16줄기 × 16종: 예 빙결·유도탄·매혹 등). 기획서 원칙 4 '형태마다 고유 기능 없음'을 이 범위에서 바꾼다. 같은 줄기 안에서는 단계가 오를수록 강해진다. 바로 위의 '발사체는 모양·수치 차이만' 결정을 대체한다.
- 상태이상(빙결·매혹 등)은 나보다 높은 단계의 적에게 단계 차이만큼 약해진다(1단계 위 = 지속 절반, 2단계 위 = 1/4).
- 매혹된 적은 잠시 내 편이 되어 다른 적을 사냥하고, 그 사냥으로 얻는 요력은 내 요력으로 쌓인다. 내 편인 동안 나를 먹지 않는다.
- 여의주 강화 레벨은 피해·발사 수(기존 표)와 능력 수치(지속·범위 등)를 함께 올린다.
- 게임 템포 기본값 3 → 3.9(전체 속도 1.3배). 속도 곡선(1/3배→1.5배)은 이 위에 곱해진다.
- 부스터(플레이어 전용): 우하단 발사 버튼 위쪽 버튼. 누르는 동안 가속하고 부스터 게이지(기본 2초)가 닳으며, 떼면 자동 회복. 배율 = 1.3 × 진화 줄기 보정(0.9~1.2) + 이동 속도 강화 레벨 × 0.02, 속도 곡선이 적용된 현재 속도에 곱한다.
- 플레이어 기본 이동 속도 218 → 262(1.2배). 적 속도·템포는 그대로.
- 초반 적 이동 속도: 플레이어 1단계일 때 70%, 2단계 85%, 3단계부터 100%(config enemy.earlySpeedMult). 적 구슬 속도는 그대로.
- 형태 170종·줄기 16개·능력 16종 설계 확정: docs/design-forms-abilities.md(9절에 사용자 결정 5건). 구현 순서 T1 데이터·규칙 → T2 그림(Codex) ∥ T3 능력(Sonnet) → T4 통합 검수.
- 부스터 완료: 버튼은 지도 상자 왼쪽(우하단 발사 버튼 위 영역), 게이지는 화면 시간 기준 2초.
- [버그 수정] 화면을 다 채우는 적: 3단계 적이 요력을 전부 몸집 강화로 써서 지수적으로 커지던 문제. 적 크기 ≤ min(600, max(70, 플레이어 크기 × 2.5)), 판 안 몸집 강화는 3번까지(config enemy.growthCap).
- 판을 처음 시작할 때 적은 모두 1단계에서 시작한다(스스로 먹고 진화). 플레이어가 1단계인 동안은 보충되는 적도 1단계(stageWeights[1] = 1단계 100%).

## 변경 이력 4 — 고레벨 밸런스 (사용자 결정, 2026-11-23)
- 원인(속도): 속도 곡선 f가 템포와 플레이어 속도에 두 번 곱해져 플레이어 체감이 f²(1단계 대비 5단계 약 20배)였다.
- 속도: 진화 단계 곡선은 템포에만 곱한다(단계별 1/3, 0.6, 0.85, 1.0, 1.1). 이동 속도 강화는 플레이어 속도에만 레벨당 +4%(+10이면 1.4배). 5단계·속도 +10에서 플레이어 체감은 1단계 대비 약 4.6배.
- 원인(크기): 5단계는 최고 단계라 아래 단계 적이 2~5배 커야 나를 먹고, 적 크기는 플레이어의 2.5배·자가 진화는 플레이어 단계+1로 막혀 있어 사실상 위협이 없다.
- 크기: ① 성장 둔화(클수록 같은 먹이로 덜 자람) ② 크기 유지비(일정 크기 이상이면 초당 조금씩 줄어 균형점에서 멈춤) ③ 맞수 대요괴(4·5단계에서 같은 단계, 내 크기 0.8~1.3배 적이 주기적으로 등장) ④ 승천 목표(5단계에서 목표 크기에 닿으면 판 승리·큰 요력 보상).
- 여의주 판매가 상향: +5 300 / +10 5,000 / +15 100,000(기하 보간). 강화 비용은 예전 곡선(+5 100 / +10 1,000 / +15 10,000) × 0.2 그대로.
- 여의주 강화 연출: 강화를 누르면 0.8초 긴장(빛 모임·화면 떨림) → 결과 폭발(성공 빛·큰 글자·종소리, 대성공 폭죽·번쩍임, 실패 금 가는 연출, 파괴는 깨짐), 탭하면 건너뜀. 효과음은 Antigravity가 파일로 만든다.
- 저장 슬롯 3칸 + 자동 저장. 첫 화면에서 슬롯별 [이어하기 / 새로 시작 / 지우기].
- [정비] 버튼: 판을 멈추고 강화·진화·여의주·상점 화면을 연다. 닫으면 같은 판이 이어진다(진화하면 크기만 처음으로).
- 상점: 여의주(+0~+5, 구매가 = 같은 레벨 판매가 × 2.5)와 새 무기 종류 '보패'(설계 필요: docs/design-weapons.md). 사서 바로 팔아 이득을 보는 구멍이 없어야 한다.
- 시작 크기 1/3: 플레이어·적 모두 예전의 1/3 크기에서 시작(startSize 28 → 28/3). 크기에 묶인 값(진화 초기 크기, 점수 기준 크기, 적 몸집 상한, 특수 적 피해·치명 크기, 보물 처치 크기, 여의주 기본 피해)도 1/3. 카메라 배율은 기준 크기 28을 유지해 화면에서도 1/3로 보인다.

## 변경 이력 6 — 크기별 감속·단계별 시야·진화 연출·종족 선택 (사용자 지시, 2026-11-23)
- 이동 속도는 크기가 클수록 느려진다(플레이어·적 모두). 배율 = (시작 크기 / 크기)^0.3, 최소 0.25. 크기 150이면 약 0.43배.
- 종족(단계)이 바뀌면 나와 적이 함께 자라서 맵이 더 커진 것처럼 보이게 한다: 단계마다 카메라가 한 칸 물러선다(판을 그 단계로 시작할 때 배율 1, 0.5, 0.33, 0.25, 0.2). 월드 크기와 판정은 그대로(시야만).
- 판 안 진화도 마찬가지: 진화하는 순간 카메라는 확대되지 않고 직전 배율 × 0.69(시야 ×1.45)까지 천천히 물러서고, 속도는 진화 직전 크기 기준으로 이어 가다가 서서히 빨라지며, 단계 템포도 15초에 걸쳐 새 값으로 올라간다.
- [최종] 진화한 뒤의 실제 화면과 나·적의 크기는 처음 시작 화면과 같다(stageZoom 모두 1). 맵이 커지는 모습은 진화하는 순간의 연출로만 보여 준다: 카메라가 직전 × 0.69까지 물러서 잠깐 머물고 맵이 번지는 고리가 퍼진 뒤 시작 화면 배율로 돌아온다. 속도도 진화하는 순간과 새 판 시작 때 처음 시작 템포(1/3)로 돌아가 나와 적이 함께 느려졌다가 함께 빨라진다(paceTauSec 40초). 위의 시야 확대(×2.5, 30% 축소 ×1.45)는 이 결정이 대체한다(docs/balance-v4.md 14절).
- 글꼴은 프리텐다드(눈누 694번, SIL OFL 1.1)로 통일했다. 한자는 시스템 글꼴로 대체(docs/balance-v4.md 13절).
- 종족 선택: 진화 선택지에 ①②에 없는 방위의 입구 형태를 더해 네 종족을 식성과 무관하게 고를 수 있다. 판 안에서는 진화를 살 수 있으면 선택지를 모두 보여 준다(+ 거절용 카드 한 장).
- 단계마다 맵이 커진다(사용자 지시 2026-11-23): 월드 4000 → 6000 → 8000 → 10400 → 13200, 적 72 → 284마리(populationExp 1.15). 판을 그 단계로 열고, 판 안 진화에서는 옛 월드를 새 월드 정중앙으로 옮기고 바닥을 다시 그리며 새 땅은 보충으로 채운다(balance.map, docs/balance-v4.md 12절).
- 수치·실측·주의점: docs/balance-v4.md 10·11절. 설정: config balance.sizeSlow, balance.view, balance.evolveSlow.
- 3단계 이후 난이도(사용자 지시 2026-11-23: 적이 너무 약하고 적다): 적 단계표를 높이고(평균 2.26·2.9·3.45 → 3.35·3.78·4.21), 판 시작 때 적도 처음부터 높은 단계(예전 모두 1단계), 큰 적 비율 0.2 → 0.4, 적을 시작 장소 반경 260~1500(먹이는 120~1500)에 75% 모으고 보충도 플레이어 둘레 화면 밖에서(고리는 화면 크기에 맞춤), 판 안 진화로 3단계가 되면 멀리 있는 낮은 단계 적을 85% 정리(docs/balance-v4.md 15절).

## 변경 이력 9 — 난이도 이지·노말·하드 (사용자 지시, 2026-11-23, 세부는 추천안으로 정함)
- 지금 버전 = 노말. 난이도는 저장 슬롯(캐릭터)마다 '새로 시작' 때 고르고, 만든 뒤에는 바꾸지 않는다. 기존 저장은 노말.
- 이지: 노말 기준으로 나보다 낮은 단계 적의 출현 가중치 ×1.4(그다음 합이 1이 되게 다시 나눔), 1단계처럼 단계가 같을 때는 나보다 작은 적 크기 구간 가중치 ×1.4.
- 하드: 나보다 높은 단계 적의 출현 가중치 ×1.4, 단계가 같을 때는 나보다 큰 적 크기 구간 가중치 ×1.4. 목숨 10개: 판이 먹히거나 쓰러져 끝날 때마다 1개 줄고, 0이 되면 그 캐릭터(저장 슬롯)가 지워진다(마지막 안내 후 시작 화면으로). 승천으로 끝난 판은 목숨을 쓰지 않는다.
- 표시: 시작 화면 슬롯 카드에 난이도·남은 목숨, HUD에 하드면 목숨 수, 결과창에 '남은 목숨 N'.
- 이지 모드 부스터 강화(사용자 지시 2026-11-23): 이지에서는 부스터 배율(속도 증가분이 아니라 부스터를 켰을 때의 최종 속도 배율)을 1.5배로 한다. 예: 노말 1.3배 → 이지 1.95배. config difficulty.easy.boosterMult 1.5.
- [변경] 이지 모드(사용자 지시 2026-11-23, 바로 위 '이지 부스터 1.5배'를 대체): 부스터를 없앤다(버튼 숨김, Shift 무시). 내 기본 이동 속도는 노말의 2배에서 시작하고 적 속도는 그대로. 발사체는 쿨타임이 찰 때마다 자동으로 계속 나간다(방향은 수동 발사와 같은 규칙: 이동 방향·무기 조준 규칙), 발사 버튼은 숨긴다. 노말·하드는 그대로(수동 발사·부스터).
