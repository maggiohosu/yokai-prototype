# 기획서 원문 (사용자 확정, 2026-11-22)
게임: 「요괴 키우기」(가제: 미물에서 용까지). 휴대폰 브라우저용 재미 확인 시제품.

## 2. 확정 원칙 (바꾸려면 사용자 확인 필요)
1. 게임 밸런스에 과금 요소 없음. 확률·강화·진화에 돈이나 광고 보상이 닿지 않음.
2. 광고는 판 사이 전면 광고만. 보상형 광고 없음. (시제품에는 광고 없음)
3. 그래픽은 부품 조립식. 형태별 통짜 그림 대신 몸통 + 부품 조합.
4. 형태마다 고유 기능을 만들지 않음. 공통 효과와 보물 공격의 조합, 수치로만 차이를 냄.
5. 확률 결과를 먼저 정하고, 연출은 그 결과를 보여주기만 함. 가짜로 아깝게 보이는 연출 금지.
6. 확률 층은 최대 7개: 본체 강화, 대성공, 등급, 미지의 진화, 카드 희귀도, 섭식 크리티컬, 보물 강화.
7. 화폐는 '요력' 하나. 진화, 본체 강화, 보물 강화 모두 요력으로 함.

## 3. 게임 요약
- 작은 미물로 시작해 산해경·동양 설화의 요괴를 잡아먹고, 여의주 같은 보물로 큰 요괴를 깎아 쓰러뜨리며, 요괴나 신선이 되어 용에 이르는 게임.
- 템포: Snake.io처럼 빠르게. 한 판 1~3분.
- 핵심 재미: ① 다음에 뭐가 될지 궁금함 ② 보물을 빠르게 강화하다 팔고 다시 강화 ③ 쫓기던 큰 요괴를 깎아서 역전해 잡아먹기.

## 4. 핵심 규칙
- 크기 = 체력. 큰 쪽이 작은 쪽을 먹음. 보물로 맞히면 상대 크기가 줄고, 나보다 작아지면 먹을 수 있음. 역전 순간 "역전!" 표시, 상대는 도망으로 전환.
- 조작: 세로 화면. 왼손 가상 조이스틱(화면 왼쪽 아무 곳이나 누르고 끌기)으로 이동, 오른손 발사 버튼.
- 조준: 버튼은 수동, 방향은 이동 방향 앞쪽 부채꼴 안에서 가장 가까운 큰 요괴를 자동 조준. 대상이 없으면 이동 방향으로 발사. 쿨타임 있음.
- 몸이 커질수록 카메라 줌아웃.
- 적 AI 3규칙: 나보다 작으면 도망, 크면 추격, 그 외 배회.
- 요괴는 사방 4색: 동·청, 서·백, 남·적, 북·흑. 맵 구역마다 많이 나오는 색이 다름.
- 먹히면 판 종료. 얻은 요력, 식성, 성향, 보물은 유지.

## 5. 진화 방향 두 축
- 식성: 현재 단계에서 먹은 색별 양. 4색 막대로 표시. 진화하면 초기화.
- 성향(요기 ↔ 선기): 직접 잡아먹으면 요기 상승(원래 나보다 컸던 요괴를 먹으면 크게), 보물로 깎아 쓰러뜨리거나 보물 강화에 성공하면 선기 상승. 음양 게이지로 표시.
- 진화 선택지 3개: ① 정규 진화 중 식성 1위 방위·성향에 가장 맞는 것 ② 두 번째로 맞는 것(정규 진화가 1개면 같은 단계에서 식성·성향이 맞는 형태) ③ 미지의 진화(???, 같은 단계 무작위).
- 진화 비용: 요력 기준치.

## 6. 등급
- S+, S, A, B, C, D, E, F. 기본 확률: S+ 1% · S 4% · A 10% · B 20% · C 25% · D 20% · E 12% · F 8%.
- 본체 강화 레벨 합계가 높을수록 높은 등급 확률이 오름.
- 등급은 효과 수치(S+ ×2.0 ~ F ×0.5)를 정하고, 겉모습은 빛·테두리로만 표현.
- 확률은 게임 안에 표시.

## 7. 본체 강화
- 능력치 3종(크기 성장, 이동 속도, 대표 효과) 중 하나를 +1~+10 강화. 비용은 요력.
- 성공률: +1 95%, +2 90%, +3 80%, +4 70%, +5 60%, +6 50%, +7 40%, +8 30%, +9 20%, +10 10%.
- 실패 중 퇴화 비율: +4까지 0%, +5~6 30%, +7~8 40%, +9~10 50%.
- 퇴화하면 플레이어가 선택: A. 강화 1 하락 / B. 역진화(강화 유지, 진화 단계 1 낮추고 새 선택지로 재진화, 등급 새로 굴림). 1단계에서는 B 불가.
- 천장: 실패·퇴화마다 다음 성공률 +5%p, 성공 시 초기화.
- 대성공: 성공 중 5%는 +2단계.
- 연속 강화: 목표를 정하면 자동으로 빠르게 시도하고, 퇴화·대성공·S급 관련 결과에서 멈춤.
- 보호권: 퇴화 1회 방지. 황금 요괴, 최초 발견, 파편 교환으로 획득.

## 8. 보물 강화·판매
- 보물: 여의주(유도 구슬)만 이번에 구현. (검·부채·호리병·방울은 나중)
- 요괴를 쓰러뜨리면 확률로 보물이 떨어짐. 보물로 깎아서 쓰러뜨리면 드롭 확률이 더 높음. 1개 장착, 보관함 5칸.
- 강화 +1~+15. 성공률: +1~+5는 90→70%, +6~+10은 60→40%, +11~+15는 30→10%.
- 실패 시 깨짐 확률: +5까지 0%, +6~+10은 10→20%, +11~+15는 30→50%.
- 판매가(요력): +5에 100 정도, +10에 1,000 정도, +15에 10,000 정도로 급격히 상승. 강화 비용은 판매가의 약 20%.
- 강화 레벨이 오르면 공격력, 발사 수, 충전 요술이 강해짐.
- 깨지면 파편이 남고, 파편을 모으면 보호권과 교환.
- +10 이상이면 "+12 천둥 여의주" 같은 칭호.

## 9. 진화표 (이번엔 1~3단계 17종)
- 1단계: 미물(작은 벌레)
- 2단계: 동·청 새끼 뱀 / 서·백 새끼 범 / 남·적 새끼 새 / 북·흑 새끼 거북
- 3단계 (방위마다 요 2, 선 1):
  - 동·청: 청구 여우(요), 이무기(요), 청학(선)
  - 서·백: 박이(아홉 꼬리 양, 요), 천구(요), 백록(선)
  - 남·적: 필방(외다리 불새, 요), 도깨비(요), 선동(선)
  - 북·흑: 수귀(요), 두억시니(요), 현구(검은 거북, 선)
- (참고) 4·5단계와 숨겨진 완전체는 다음 버전.

## 10. 그래픽
- 그림 파일 없이 코드로 그리는 귀여운 캐릭터. 둥글고 통통한 몸, 큰 눈과 흰 하이라이트, 볼터치, 짧은 팔다리, 밝은 색, 굵은 외곽선.
- 방위 색으로 몸통 색. 선 갈래는 흰 기운 테두리, 요 갈래는 붉은 눈빛.
- 형태 차이는 부품으로: 꼬리 개수, 머리 개수, 뿔, 깃털·박쥐 날개, 외다리, 여섯 다리, 비늘, 등껍질, 갈기, 도포 깃, 상투·관, 사슴뿔, 불꽃 등.
- 같은 형태는 언제나 같은 부품 조합. 기존 게임·애니메이션 캐릭터와 닮지 않게.
- 진화 결과 화면에 이름과 한 줄 설명을 크게. 예: "상류 — 아홉 머리로 아홉 산을 삼킨 뱀"

## 11. 범위와 순서 (단계마다 게시)
1. 이동, 4색 요괴 먹기, 크기 판정, 적 AI, 카메라 줌아웃
2. 발사 버튼, 여의주 구슬, 자동 조준, 크기 깎기, 역전 표시
3. 요력, 식성·성향 기록, 1~3단계 진화(선택지 3개, 등급)
4. 판 사이 화면: 본체 강화(퇴화 A/B 포함), 여의주 강화·판매
5. 진행 상황 저장(다시 열어도 이어서)
- 이번에 빼는 것: 광고, 결제, 판 안 레벨업 카드, 섭식 크리티컬, 4~5단계, 환생·계보, 다른 보물, 화려한 연출.
